# BUG Clicker

바탕화면 위에 캐릭터를 띄워 두고, 누르면 딸깍 소리와 함께 말풍선으로 대답하는 Windows 프로그램입니다.

## 내려받기

**[BUG-Clicker.exe 내려받기](https://github.com/BUG-INVADE/Bug-Clicker-download/releases/latest/download/BUG-Clicker.exe)** · Windows 10 · 11 (64비트)

- 설치 없이 exe 를 바로 실행합니다. 처음 켜면 사용 안내가 나옵니다.
- 캐릭터 · 설정은 exe 옆 "BUG Clicker 데이터" 폴더에 저장됩니다. 둘을 함께 옮기세요.
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
- 새 버전은 프로그램이 알아서 받아 둡니다. (설정 → 정보 → 업데이트)
